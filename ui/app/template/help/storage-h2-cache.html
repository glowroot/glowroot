H2 cache — in-memory page cache for H2 (same JVM heap as the app), not disk storage.
  • Auto — targets 128 MB.
  • Fixed MB / % of -Xmx — your target before clamping.
  • Clamp — effective size is always between 16 and 256 MB, and at most 5% of -Xmx.
Optional override: -Dglowroot.internal.h2.cacheSize (KB) wins over the UI. Raise only if H2 is I/O-bound and heap allows; too large steals memory from the application.

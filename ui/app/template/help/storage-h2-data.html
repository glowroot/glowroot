data.mv.db — main H2 file; settings are days (time retention), not file size.
  • 1 min → 4 hour aggregates — how long to keep response-time and JVM gauge charts at each resolution. Finer intervals use more disk for the same history.
  • Trace data — days to keep trace points/headers (Traces tab).
  • Full query text — days for full SQL text. Truncated text and query stats follow *.capped.db size limits.
Large file? Use Maintenance → Analyze / Compact. Changing days only affects future expiry.

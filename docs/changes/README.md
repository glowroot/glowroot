# PR change notes

Per-PR notes that record **what / why / how / choices** for fixes and features.

- Template: [pr-change-template.md](../pr-change-template.md)
- Policy: [CONTRIBUTING.md — Pull requests and change documentation](../../CONTRIBUTING.md#pull-requests-and-change-documentation)

Add one Markdown file per non-trivial PR (`<short-slug>.md`) and link it from
the PR description. Prefer updating a lasting topic page under `docs/` instead
when the change documents enduring operator-facing behavior.
